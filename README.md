# Wallpaper-homepage · Wallpaper OS

纯前端个人主页已升级为可自由排列组件的个人桌面。只使用 HTML、CSS、原生 JavaScript 与浏览器本地能力，可直接部署到 GitHub Pages、Vercel、Netlify 等静态托管，不需要服务器、数据库、账号或构建步骤。

## 桌面功能

- **自由布局**：点击顶部「排列」，拖动组件标题栏移动窗口，拖动窗口右下角调整尺寸；布局会保存在当前浏览器。
- **桌面组件**：个人资料、时钟/日期、搜索、灵感一言、快捷导航、工具箱、便签与待办、壁纸主题、视觉特效、音乐播放器、RoboCode。
- **导航管理**：添加网址、删除网址，链接在本机浏览器保存。
- **主题与壁纸**：星云、深海、樱花、森林、暮色、月白六套主题；支持上传本地图片（建议 2 MB 以内）。
- **个人工具箱**：四则计算器、JSON 格式化/压缩、随机数生成器。
- **本地数据**：便签、待办、布局、主题和导航保存在 localStorage；使用顶部「备份」导出 JSON，使用「导入」恢复。
- **视觉特效**：可开关环境粒子、鼠标跟随、背景暗化与动画。
- **RoboCode**：从桌面组件进入独立的编程闯关页面。
- **离线壳缓存**：Service Worker 会缓存主页、游戏页和核心静态资源。首次在线打开一次后，浏览器支持且缓存完成时可离线访问已缓存页面。

## 使用

1. 打开主页。
2. 点击顶部「排列」后拖动组件标题栏，自由摆放窗口；拖动窗口右下角可调整大小。
3. 点击「＋ 组件」显示隐藏组件；底部 Dock 可快速重新显示组件。
4. 用「备份」导出本机数据，换浏览器或清除浏览器数据前请先备份。

## 本地运行

推荐通过本地静态服务器运行（Service Worker 需要 localhost 或 HTTPS）：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。也可以直接打开 `index.html` 使用大部分功能，但离线缓存不会在 `file://` 下注册。

## 数据与限制

- 没有后端：不同设备和浏览器之间不会自动同步数据。
- 壁纸、便签、待办和设置保存在本机浏览器；清除网站数据会删除它们，重要内容请先导出备份。
- 一言需要联网刷新；断网时会回退到内置句子。
- Service Worker 需要首次联网加载并缓存资源后才能提供离线体验；外部搜索站点、远程图片和在线 API 本身不保证离线可用。
- 自定义壁纸建议压缩到 2 MB 以内，以免占用过多浏览器本地存储空间。
